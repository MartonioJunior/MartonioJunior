### Hi there 👋

I'm Martônio Júnior, a developer with a decade of programming experience in many different languages and environments who specializes in Swift, Apple Platforms and Unity.

## ⭐️ Highlights

### Swift
- [Website](https://github.com/MartonioJunior/martoniojunior.github.io): My personal website, implemented in Swift.
- [Firewall](https://github.com/MartonioJunior/swift-firewall): A micro package reimplementation of the Firewall game programming pattern in Swift.
- [Mathe](https://github.com/MartonioJunior/Mathe): Toolbox of Math utilities.
- [Minimal](https://github.com/MartonioJunior/Minimal): Utilities for functional programming.
- [Shades](https://github.com/MartonioJunior/Shades): Toolbox of graphics-related utilities.
- [swift-bytecode](https://github.com/MartonioJunior/swift-bytecode): A generics-based implementation of the Bytecode pattern in Swift with support for Stack and Register-based approaches.
- [swift-chance](https://github.com/MartonioJunior/swift-chance): Reimplementation of Chance in Swift.
- [swift-evaluation](https://github.com/MartonioJunior/swift-evaluation): Toolbox of testing-based utilities (mostly focused around Swift Testing).
- [swift-memento](https://github.com/MartonioJunior/swift-memento): Micro package implementation of the Memeto pattern in Swift.
- [swift-molecules](https://github.com/MartonioJunior/swift-molecules): Micro pacakge for using value types as reference types.
- [swift-multicast-delegate](https://github.com/MartonioJunior/swift-multicast-delegate): Micro-package generics-based implementation of the Multicast Delegate pattern in Swift.
- [swift-trinkets](https://github.com/MartonioJunior/trinkets-swift): Collection of custom patterns for implementing gameplay features (includes a partial reimplementation of Apple's Measurement API using static units)
- [swift-variety](https://github.com/MartonioJunior/swift-variety): Small package to improve ergonomics of working with heterogeneous structures in Swift in a type-safe manner.
